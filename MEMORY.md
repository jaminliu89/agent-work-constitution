# Project Memory

This is a public, curated record of durable project decisions. Do not store private identity, secrets, financial details, access tokens, or internal company information.

## 2026-10-24 — Initial decisions
- The repository publishes our original, vendor-neutral agent work rules inspired conceptually by the community project *Karpathy-Inspired Claude Code Guidelines*.
- Keep Karpathy-style engineering discipline (think before coding, simplicity, surgical changes, verifiable goals) while adding user-outcome focus, history/constraints recall, authorized decision states, truthful verification, mainline control, and transferable learning.
- Separate universal instructions (`rules/`) from the repository's own contribution guidance (`AGENTS.md`) and the example project templates (`templates/`).
- English and Simplified Chinese are first-class; all public claims must remain testable and accurate.
- No automatic new-repository creation or public GitHub publication is implied by preparing these files.
