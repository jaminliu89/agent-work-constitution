# Contributing

Thanks for helping improve these agent instructions. We favor compact, tested changes over adding more rules.

1. Open an issue or describe a concrete failure mode and an example task.
2. Explain which existing rule fails and how the proposed change affects agent behavior.
3. Make the smallest edit possible. Keep Chinese and English versions equivalent in meaning.
4. Check Markdown links, clarity, contradictions and risks (especially unauthorized actions and invented verification).
5. Include an observed before/after example where possible. Label hypothetical examples as hypothetical.

Please do not include secrets, private repositories, internal customer data, full private conversation transcripts, or copied material without compatible rights and proper attribution. This project is not affiliated with Karpathy or any AI vendor.
