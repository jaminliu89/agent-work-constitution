# Agent Instructions — This Repository

Read this file and `MEMORY.md` completely before changing this repository.

## Purpose
Publish a lightweight, vendor-neutral set of practical AI-agent guidelines in English and Simplified Chinese. This repository contains public, general-purpose instructions only; never commit private business context, credentials, conversation transcripts, or identifiable customer data.

## Working rules
- Think before coding; disclose material assumptions and trade-offs.
- Prefer simple, surgical changes tied directly to an approved issue or task.
- Define acceptance criteria and verify before claiming success.
- For instruction changes, update both `rules/CONSTITUTION.md` and `rules/CONSTITUTION.zh-CN.md` or explicitly document a translation gap.
- Keep entrypoints concise; maintain the canonical principles in `rules/` instead of duplicating the entire text across integrations.
- Check all relative links and public-safety constraints before publishing.
- Record durable decisions and relevant lessons in `MEMORY.md`, not transient status updates.
- If a relevant task is repeated three times, evaluate automation but don't automatically build it.

## Decision and publishing boundaries
Unapproved ideas do not become requirements. Do not copy another project's protected text. Attribute conceptual inspiration; this is not an official Andrej Karpathy or Claude project. Never claim a GitHub release, deployment, or real-world validation without evidence.
